# Initial SmartUrbanity main-history question pool

This data-only pool (version 1.0.0) is built exclusively from the pinned SmartUrbanity main first-parent history, including v0. No proposed-review branch definitions or former PlanEasy scientific definitions are imported. The pinned reference supplies names and privacy labels only. All definitions remain draft.

A stable family ID owns exact immutable schema/translation revisions. The current main declared question version is reserved; older distinct meanings receive chronological 0.N.0 versions. Exact meaning reuse shares a revision. Any distinct current meanings claiming the same version require an explicitly reported patch allocation and pointer mapping. Current files select the most frequent main pin with a SemVer tie-break; absent families retain their latest historical meaning and are marked inactive.

Scientific schema preserves response keys (including their absence), text, option order and actual/missing values. Only root flow fields, identity/version transport and legacy alias fields are separated. Legacy privacy metadata is normalized conservatively into one question-root classification with provenance; it is not a legal determination. Relevant translations are copied only from dictionaries in the exact source blob, including present generated escape/other-input labels.

Full questionnaire bodies are not embedded. questionnaire-history records ordered section titles/hub features, exact question pins and unchanged flow overrides, plus immutable Git source pointers and blob/node hashes. Source Git remains authoritative for complete historical questionnaire reconstruction. SmartUrbanity runtime files are not written by this builder.

The feed contains every immutable revision, zero flows and empty initial reviews. topics.json provides additive multi-topic grouping; IDs and storage paths remain independent of topic/project labels. New families lacking topic assignments are explicitly marked needs_review. proof.json verifies occurrence coverage, source equality, dictionaries, unique pins, hashes and current selection.
